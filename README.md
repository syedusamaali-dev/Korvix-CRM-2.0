# 🚀 Getting Started

Clone Repository

```bash
git clone https://github.com/syedusamaali-dev/Korvix-CRM-2.0.git
```

Open Project

```bash
cd Korvix-CRM-2.0
```

Install Dependencies

```bash
npm install
```

Run Project

```bash
ng serve
```

Open

```
http://localhost:4200
```
